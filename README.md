# visionpal-ai-smart-glasses

## Introduction


VisionPal is an AI-powered smart glasses system designed to assist visually impaired individuals through real-time object detection, distance awareness, and voice-based navigation assistance.

## Features
- Real-time object detection
- Distance measurement
- Direction detection
- Voice assistance
- Scene description
- Raspberry Pi implementation
- Low-cost wearable prototype

## Technologies Used
- Python
- OpenCV
- YOLOv4 Tiny
- Raspberry Pi
- Ultrasonic Sensor
- pyttsx3
- NumPy

## Hardware Components
- Raspberry Pi 4
- Pi Camera Module
- HC-SR04 Ultrasonic Sensor
- Speaker/Earphones
- Smart Glasses Frame

## System Workflow

Camera → YOLO Detection → Distance Sensing → Direction Detection → Voice Output

## Sample Outputs

- “Person on your left”
- “Obstacle nearby”
- “Bottle detected in center”
